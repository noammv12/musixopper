# הרצה ראשונה של Palon v10 — צ'קליסט

גרסה 9 נבנתה במקביל על ידי כמה סוכנים ועוד לא הורצה על Windows. עבור על הרשימה לפי הסדר, סמן ✓, ורשום כל דבר מוזר (גם קטן). בסוף יש רשימה של מה לשלוח אם משהו נשבר.

## v10 — מה חדש ומה לבדוק

שלושה חלקים שנבנו במקביל חוברו לחוויה אחת: חלון **עכשיו**, **הדוק החדש**, ו**המוח האג'נטי**. לבדוק במיוחד:

- [ ] בלוג: `Palon 10… starting`, `Agentic: nudge engine started`, בלי `Agentic: wiring failed`.
- [ ] **Ctrl+Alt+R** מכל אפליקציה פותח את שדה החזרה בדוק; "דני מחר 11" + Enter קובע. בהגדרות (Ctrl+9) אפשר להחליף ל-Ctrl+Alt+B או לכבות.
- [ ] שורת הפקודה בעכשיו: "דני מחר ב-11" → תצוגה מקדימה → אישור → טוסט עם **בטל** (בודק שהביטול מוחק). אותו דבר כשהחלון מאחור (הטוסט מופיע בדוק, לחיצה מבטלת).
- [ ] "נסח הודעה ל…" / "מה עכשיו" / "בריף" → כרטיס תוצאה ליד Palon עם **העתק** ו-✕. כשהחלון סגור — הוא נפתח.
- [ ] Nudge: מופיע ליד Palon (עד 2) ובדוק (כרטיס אחד, רק כשעכשיו לא בחזית). סגירה באחד נעלמת גם בשני.
- [ ] בוקר ראשון: מסך הבריף מציג חזרות, קצב והזדמנויות; עם מפתח AI מופיע גם משפט פתיחה של Palon.
- [ ] טבעת השיחות — אותו יעד בעכשיו ובדוק (הגדרות → יעד שיחות יומי, ברירת מחדל אוטומטי).
- [ ] הגדרות → תבניות מוצמדות: שינוי מתעדכן מיד בשורת הריחוף של הדוק.
- [ ] פוקוס (הגדרות או "פוקוס שעה"): אין הצעות יזומות, חזרות שקבעת עדיין מגיעות.
- [ ] RTL/DPI: כרטיס התוצאה והגדרות במסך 125%/150% — טקסט לא נחתך, עברית מיושרת לימין.

## 0. לפני שמתחילים

- [ ] Quit לגרסה הישנה (אייקון במגש → Quit).
- [ ] גיבוי: העתק את `%LOCALAPPDATA%\Palon\` לתיקייה בצד (הערות, חזרות, סטטיסטיקות). v9 ממיר את `reminders.json` לפורמט חדש (שומר `reminders.v1.bak.json`), אבל עדיף עותק משלך.

## 1. בנייה / התקנה

- [ ] או: להוריד `Palon.exe` מה-artifacts של ה-build האחרון ב-GitHub Actions.
- [ ] או לבנות בעצמך (Windows, .NET 8 SDK):
  ```
  dotnet test tests/Palon.Tests
  dotnet publish src/Palon.csproj -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o publish
  ```
  `dotnet test` צריך לעבור נקי (503 טסטים עברו על Linux; על Windows זו הבדיקה האמיתית הראשונה).
- [ ] להריץ את `publish\Palon.exe` (SmartScreen: More info → Run anyway).
- [ ] לוודא: P במגש, הדוק מעל ה-taskbar, בלוג כתוב `Palon 10.0… starting` בלי שורות `Shell init failed` / `Dispatcher exception`.

## 2. מפתחות ומודל

- [ ] Flyout → Notes & dictation: מפתח Groq (תמלול) + מפתח Gemini ו/או DeepSeek.
- [ ] Terminal → לחיצה על הלוגו (brain sheet): כפתור **Test** לכל מפתח — צריך ✓ וזמן במילישניות.
- [ ] בחירת מודל (Model picker): להשאיר **אוטומטי**, או לבחור אחד ולוודא שהתשובות ממשיכות לעבוד.
- [ ] ⚠️ **Gemini free tier:** Google רשאית להשתמש בפרומפטים ובתשובות (כולל קריאה אנושית). אלה תמלולים של לקוחות — עדיף מפתח Gemini **בתשלום** (billing פעיל) או DeepSeek. בנוסף ה-quota היומי בשכבה החינמית על 3.8 Flash קטן מאוד.

## 3. שם

- [ ] Terminal → לחיצה על הלוגו (brain sheet) → שדה השם. לוודא שהברכה ב-Today מופיעה נכון בעברית.

## 4. ייבוא גיליון ספטמבר

- [ ] Terminal → **Month** (Ctrl+3) → לנווט לספטמבר → **ייבוא מאקסל** → לבחור את ה-xlsx.
- [ ] לבדוק את ה-preview: מספר עסקאות, אזהרות שורה (תאריך/אזור/מקור לא מזוהים), סכומים.
- [ ] לשמור ולוודא: סך ההפקדות, ה-bonus, ה-pace (ימי עבודה א׳–ה׳) נראים נכון מול הגיליון המקורי.
- [ ] להכניס יעד חודשי ולראות את **40/55** בדוק בריחוף.

## 5. שיחת בדיקה

- [ ] Notes & dictation → **Take notes on my calls** פעיל.
- [ ] לעשות שיחה אמיתית קצרה (למשל לעצמך מהנייד, 1–2 דקות), להגיד בה משפט עם זמן חזרה: "אחזור אליך מחר ב-11", ועובדה: "אשתי קוראים לה מיכל".
- [ ] מוזיקה נעצרת וחוזרת. בדוק שה-caller brief מופיע כשמספר מוכר מתקשר.

## 6. כרטיס אחרי שיחה בדוק

- [ ] אחרי השיחה הדוק **מתרחב (morph)** לכרטיס: "השיחה עם … הסתיימה", שורת הסיכום, צ'יפים של **"מתי לחזור?"** — "מחר 11:00" כבר מסומן.
- [ ] לחיצה אחת קובעת חזרה (עם Undo). **העתק סיכום** מעתיק טקסט מוכן ל-Salesforce.
- [ ] הכרטיס מתקפל לבד אחרי ~20 שניות; ✕ סוגר.

## 7. חזרות (Callbacks)

- [ ] Terminal → Callbacks (Ctrl+2): החזרה מהשיחה מופיעה; החזרות הישנות הומרו.
- [ ] ליצור חזרה בעוד 2 דקות ("תזכיר לי לחזור לדני בעוד 2 דקות") — כשהיא מגיעה: כרטיס "הגיע הזמן לחזור ל…", **+10 דק׳**, **בוצע** (עם undo).
- [ ] לסגור את Palon כשחזרה ממתינה, לפתוח אחרי שהזמן עבר → מסומנת **באיחור**.

## 8. סיור ב-Terminal

- [ ] Ctrl+1…7: Today, Callbacks, Month, Clients, Templates, Coaching, Memory. Ctrl+K = Ask. Esc סוגר sheet.
- [ ] Clients: השיחה והחזרה מופיעים תחת המספר.
- [ ] Templates: להעתיק תבנית עם שם לקוח; לערוך טקסט לפני העתקה.

## 9. שאלות לנסות ב-Ask (Ctrl+K, או Ctrl+Alt+P בקול)

- [ ] "מה סיכמתי עם <המספר מהשיחה>?"
- [ ] "כמה שיחות עשיתי היום?"
- [ ] "תזכיר לי מחר ב-9 לשלוח הצעה לדני"
- [ ] "תכין הודעת פולו-אפ לשיחה האחרונה ותפתח בוואטסאפ" (צריך לבקש אישור לפני שפותח)
- [ ] "מה אני יודע על הלקוח מהשיחה האחרונה?" (recall_client)
- [ ] שאלה ארוכה עם כמה צעדים — לראות את ה-progress chips בעברית ולנסות **ביטול (cancel)** באמצע.

## 10. זיכרון

- [ ] ב-Ask: "תזכור שאני לא עובד בימי שישי" → הודעה "Palon זוכר: …". Terminal → Memory (Ctrl+7) → מופיע תחת "About you".
- [ ] "תשכח שאני לא עובד בימי שישי" → נמחק, עם undo.
- [ ] העובדה מהשיחה ("אשתו מיכל") מופיעה תחת הלקוח, עם הציטוט.
- [ ] לנסות **Pause** ולוודא ששום דבר חדש לא נשמר.

## 11. קריאת מסך

- [ ] Ask → **קרא מהמסך** → לסמן אזור → מופיע שער פרטיות עם התמונה המדויקת ושם המודל → Send → תשובה + Copy.
- [ ] Cancel בשער → שום דבר לא נשלח (אין שורת `AI vision` בלוג).
- [ ] קבלה: אפשרות הקבלה → נפתח sheet של עסקה חדשה ממולא, לבדיקה לפני שמירה.

## 12. Salesforce — הפעם הראשונה

- [ ] Terminal → כפתור **Salesforce** → Palon פותח **Edge משלו** (פרופיל נפרד `%LOCALAPPDATA%\Palon\edge-profile`). להתחבר ל-Salesforce שם פעם אחת.
- [ ] אם מופיעה הודעת policy (`RemoteDebuggingAllowed=0`) — המחשב מנוהל וזה חוסם. לשלוח צילום; כל השאר עובד.
- [ ] לפתוח **איש קשר לבדיקה (test contact)** — לא לקוח אמיתי.
- [ ] **למד את Palon** (teach mode): לבצע פעם אחת Log a Call / New Task לפי ההוראות על המסך. לוודא "נלמדו N צעדים ✓".
- [ ] **ניסיון (dry run)** על איש הקשר לבדיקה — מראה את התוכנית בלי לכתוב.
- [ ] **אישור (approve)** של כתיבה אמיתית על איש הקשר לבדיקה → לבדוק ב-Salesforce שהרשומה נכונה → לנסות **Undo** מרשימת ה-audit.
- [ ] רק אחרי זה: *ל-Salesforce* מכרטיס אחרי שיחה אמיתית.

## 13. אימון (Coaching) — אחרי כמה שיחות

- [ ] אחרי 5–10 שיחות מסוכמות: Terminal → Coaching (Ctrl+6): יחס דיבור/הקשבה, התנגדויות וציטוטים, השבוע מול הקודם, השיחה הטובה של השבוע.
- [ ] ציטוטים צריכים להיות מילה במילה מהתמלול. ביטויים שקשורים להפקדות מופיעים רק אחרי 8+ שיחות.

## 14. בדיקות Windows ספציפיות (סומנו ע"י הסוכנים)

- [ ] **Acrylic backdrop** של ה-Terminal: זכוכית אמיתית ב-Windows 11; ב-Windows 10 רקע כהה אחיד בלי שקיפות מכוערת.
- [ ] **Dock morph**: המעבר בין גלולה → בר בריחוף → כרטיס אחרי שיחה חלק, בלי הבהוב או קפיצה בגובה.
- [ ] **DPI 125% ו-150%** (Settings → Display → Scale): הדוק ממוקם נכון מעל ה-taskbar, טקסט חד, ה-Terminal לא חתוך; גרירת הדוק עובדת.
- [ ] **RTL**: עברית מיושרת לימין, מספרי טלפון ושעות לא מתהפכים, טקסט מעורב עברית/אנגלית קריא, החצים ב-Coaching מצביעים נכון.
- [ ] **Avatar ב-40px** (בדוק וב-side dock): Palon ברור ולא מטושטש, האנימציות לא כבדות (CPU ב-Task Manager כשהכל במנוחה ≈ 0%).
- [ ] **Edge remote debugging policy**: ראה סעיף 12.
- [ ] **Gemini thought_signature**: שאלה שדורשת שני סבבי כלים (למשל "מה סיכמתי עם X ותקבע לי חזרה אליו מחר ב-10") — צריכה לעבוד עם Gemini בלי מעבר ל-DeepSeek. בלוג **לא** אמורה להופיע `agent run moved Gemini → DeepSeek` או 400 על `thought_signature`.
- [ ] **Cancel**: ביטול ב-Ask באמצע תשובה, ביטול בשער קריאת המסך, Esc בהקשבה קולית — שום דבר לא נתקע ו-Palon חוזר למנוחה.
- [ ] **Test suite**: `dotnet test tests/Palon.Tests` עובר על Windows.
- [ ] מקשי קיצור: Ctrl+Alt+P, Ctrl+Alt+Space, ו-(אם הפעלת) Ctrl+Alt+Shift+S — לא מתנגשים באפליקציות אחרות (אם כן, הלוג אומר "unavailable").

## אם משהו נשבר — מה לשלוח

1. את הלוג: `%LOCALAPPDATA%\Palon\log.txt` (וגם `log.old.txt` אם קיים). ⚠️ הלוג מכיל שאלות ששאלת; לעבור עליו לפני שליחה.
2. צילומי מסך (Win+Shift+S) של מה שנראה לא נכון — עם ה-Scale שבו זה קרה.
3. מה עשית ממש לפני (הצעד מהרשימה הזו), ומה ציפית שיקרה.
4. אם store נפגם: קבצים עם סיומת `.bad` בתיקייה — Palon שמר עותק לפני שהתחיל מחדש.

לא לשלוח: את `memory\` או `edge-profile\` (מידע אישי + התחברות ל-Salesforce).
